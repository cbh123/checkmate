A · Progress bar default

One 30×8 pt bar shows how far the latest run is through its usual duration, with a short label beside it. Click it for the last 10 runs.

Menu bar states

Estimate
Median of the last 10 successful runs that match your filters. Here, CI usually takes ~3:50.
Label
62% while running · +0:32 when over the estimate · queued · ✓ / ✗ when done
Color
running over estimate passed failed queued/cancelled
Refresh
Every 10 s while a run is active, 30 s otherwise, plus each time you open the popover. Elapsed time ticks every second.
Rows
A progress bar while running; finished runs show only their duration. The default branch is omitted. Click a row to open it on GitHub.

B · Run history switch in Settings

A tiny bar chart of the last 8 runs in the menu bar: height = duration, color = result, newest on the right. The newest bar grows toward the usual height while it runs.

Menu bar states

Size
8 bars, 3 pt wide, 2 pt gap, 14 pt tall at most (38 × 14 pt). Bars are scaled to the longest run or the estimate, whichever is larger.
Label
Same as A. Text appears only while a run is active, or as ✓ / ✗ after it finishes.
Good for
Spotting flakiness at a glance (a red bar among the green), and seeing when CI is running slower than usual.
Popover
Same as A (shown here in dark mode).

Setup first launch, or the gear icon

Paste a token, then pick a repository (the menu lists your 100 most recently pushed repos) and a workflow. The branch filter and “Only my runs” are optional.
